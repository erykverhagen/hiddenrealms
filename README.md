# Hidden Realms · Blossom Village Deluxe

A single-level fantasy hidden-object web game with 10 clickable discoveries, smooth camera, magical awakened-state overlays, premium responsive collection UI, and double-tap loupe.

## Run
Deploy this folder as static files to GitHub Pages, Netlify, or any HTTPS host. There are no dependencies or build steps. `index.html` is the entry point. A standalone HTML file is also included separately for local preview.

## Controls
- Tap / click an object in the illustration to discover it. The collection updates and magical effects appear over the actual object.
- Drag to pan, pinch or mouse-wheel to zoom. Zoom out is strictly bounded to cover the viewport.
- Double-tap / double-click the scene to switch on the magnifying loupe. Single tap/click turns it off.
- Hint smoothly moves the camera to the next unfound object. Use +, -, and reset to control zoom.
- Found items are saved in localStorage on the same origin.

## Honest artwork resolution note
`assets/blossom-village-large.webp` is 7680 × 3114 pixels, but it is a Lanczos-enhanced enlargement of the **1672 × 678** source illustration. It is **not genuine natively detailed 8K artwork**. To gain new close-up detail, the source illustration must be repainted or recreated in tiled high-resolution sections. An actual 8K-grade hidden-object level would additionally require independently detailed object/scene layers.

## Scope
This is a polished first-level prototype. 100 levels and four seasonal worlds are the broader plan, not included in this package.
